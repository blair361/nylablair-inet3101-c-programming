Problem Statement:
This program converts a decimal integer into another number base between 2 and 16. This is a generalized version of the to_binary().
The function to_base_n() takes the number and the target base as inputs and prints the result. If the base is outside 2-16 then the program prints an error message. The program uses the symbols "!@#$%^" for 10-15. Octal starts with 0 and hexadecimal results start with 0x. A real life example would be if you have 30 things and a box that holds 16 of them and 14 are left I would write 1 then 14 is 2 places not one and each digit position can only hold one character so with my alphabet i write 0x1%.
